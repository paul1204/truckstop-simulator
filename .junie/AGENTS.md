# AGENTS.md

## Project Overview

This Python project represents users interacting with a lightweight truck stop ERP backend built in Spring.

## Environment

- Use Python 3.13.
- Use the existing virtual environment.
- Dependencies are listed in `requirements.txt`.
- Avoid adding dependencies unless necessary.

## Guidelines

- Keep changes small, clear, and focused.
- Treat this project as a user-activity client for the ERP, not as the ERP itself.
- Follow the existing module structure when adding or updating behavior.
- Do not modify unrelated code.

## Running

Run scripts with the configured virtual environment.

## File Structure

- `app/` contains the main application code.
- Service areas are organized into subdirectories by domain, business logic.
