# Gas Pump Simulator

This project simulates fuel pump activity for a gas station, sending HTTP requests to a backend API to mimic the sale of Diesel, Regular, and Premium fuel types.

This simulator is built to imitate how real people interact with a gas pump, generating realistic and automated test data for backend systems. Its main goal is to help test the truckstop-services repository—a Spring project that acts as custom accounting software for truckstops, managing everything from inventory to sales and other business operations.

## Features
- Simulates fuel pump activity for Diesel, Regular, and Premium fuels
- Configurable number of requests and interval per fuel type
- Modular code for easy extension and configuration
